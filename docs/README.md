# PUNTO — GitHub Pages

This folder contains the complete static website for the PUNTO Score Keeper app.

## Files
- `index.html` — Homepage
- `privacy-policy.html` — Privacy Policy
- `terms.html` — Terms & Conditions
- `support.html` — Support page
- `assets/style.css` — Shared responsive styling

## Publish with GitHub Pages
1. Create a new GitHub repository. Public is simplest for GitHub Pages.
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

Your pages will use these paths:
- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/privacy-policy.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/terms.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/support.html`

## App details reflected in the pages
PUNTO is described as an offline score keeper. The current app stores player names, scoreboards, rounds, and theme preference locally using SharedPreferences. The pages state that the current version has no account, backend, cloud sync, advertising SDK, or analytics SDK.
